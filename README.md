## About the Project

Refúgio na Floresta is an independent environment development project built in Unreal Engine 5, inspired by the setting of an original literary work.

The project focuses on creating an immersive, photorealistic forest environment featuring a luxury rustic cabin, dense vegetation, natural landscapes and environmental storytelling.

The main objective is to achieve high visual fidelity while maintaining efficient real-time rendering.

## Technical Objectives

- Photorealistic environment creation
- Dense forest and vegetation management
- Real-time lighting and shadow optimization
- Landscape and architectural development
- AI-assisted development and automation
- Performance profiling and benchmarking

## Current Development

The environment currently contains approximately 135,000 mesh instances, with a significant concentration of grass and ground vegetation.

Development is focused on balancing visual quality, environmental density and rendering performance.
